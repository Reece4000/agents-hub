This repository uses the Agent Hub Tasks canvas as shared working context: tasks, notes, and evidence-backed codebase facts in `.agents-hub/notes/`. Read `.agents-hub/README.md` before working. In an Agent Hub terminal, use the `board_*` MCP tools or the `agent-hub-board` command (`agent-hub-board summary`, then `search`, `read`, or `related`). The summary's `activeTask` is the Task your Session is working on: keep its status current and finish it with `board_complete_task`, capturing one concise, evidence-backed codebase learning. For an agent without the board tools, read the Markdown notes directly and follow the board guide.
